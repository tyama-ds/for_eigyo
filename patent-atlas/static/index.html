TRANSFORMER TRAINING

特許の要否から学習

必要・不要を各4件以上。タイトルと要約の先頭256トークンを使い、Transformer本体と分類ヘッドを3エポック微調整します。safetensors形式の対応モデルと追加パッケージが必要です。

pip install -r requirements-transformer.txt

軽量学習は追加モデル不要です。必要・不要各2件から動きます。
