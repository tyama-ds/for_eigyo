## 外見を固定する方式

3形式とも同じ描画処理で翻訳済みページを PNG にし、ページ全体を固定配置します。Word のフォント置換や段落の再配置によるずれを避けます。Word / PowerPoint 内の文章・表・図形は個別編集できません。

- PDF: 元のページごとの寸法・縦横向き。
- Word: ページごとにセクションを作り、用紙の原点に配置。用紙寸法の丸めは最大 0.025 pt。
- PowerPoint: 全ページを収める共通スライド寸法とし、各ページ画像を元の物理サイズで中央配置。用紙サイズ混在時は余白が増えます。

基準画像は翻訳後の描画結果です。この検証は、出力形式への変換によってその描画が欠けたり移動したりしないかを検証します。翻訳前の PDF と翻訳後の文字形状の完全一致を意味しません。

## 検査方法

1. 実ブラウザーで各文書を各形式へ3回出力します。3文書 × 3形式 × 3回 = 27ファイルです。別途、画面の形式選択と保存ボタンから3形式をダウンロードします。
2. PDF を再読込してページ数と寸法を検査します。Word / PowerPoint は ZIP 内の画像と配置情報を検査し、PNG の SHA-256 が基準画像と完全一致することを確認します。
3. Microsoft Open XML SDK で、UI出力を含む20個の DOCX / PPTX の文書構造を検証します。
4. Microsoft Word / PowerPoint で生成ファイルを読み取り専用で開き、Office 自身の機能で PDF に変換します。アプリとは独立した PDFium で再描画し、基準画像と比較します。
5. 各形式で長すぎる訳文を与え、`TEXT_OVERFLOW` により出力を停止することを確認します。

画像比較では位置合わせ・拡大縮小による補正を行いません。端数の画素丸めに限り、右端・下端の最大1ピクセルを補います。色の目印には、検証文書内に位置・色を明示した単色の領域を使います。文字の縁に生まれる中間色は位置の目印には使いません。アンチエイリアス差を許容するため、次の判定値を使用します。

| 指標 | 合格条件 |
| --- | --- |
| ページ数 | 完全一致 |
| 物理寸法 | 各辺の差が 0.1 pt 以下 |
| RGB平均絶対誤差 | 4 / 255 以下 |
| 0.6pxぼかし後のRGB平均絶対誤差 | 2 / 255 以下 |
| 48 / 255 を超える画素差 | 全体の2%以下 |
| 前景・色目印の境界、色目印の重心のずれ | 2px以下 |
| 白からの色の差を合計した値の比 | 0.95～1.05 |
| 単色の目印の面積比 | 0.90～1.10 |

比較器自体も、完全一致を合格とし、6pxの位置ずれ、白紙化、下部の欠け、縦横比の変形、単独の目印だけの6px移動を不合格にする6つの確認を行います。小さな文字の1画素単位の一致を保証する検査ではありません。同じ文書・形式・ページの3回の結果について、再描画 PNG のハッシュが一致することも検査します。

## 検証範囲と制約

この結果は上記の検証文書・ブラウザー・Office バージョンでの結果です。すべての PDF、Office 互換ソフト、プリンター、PDF ビューアーについて同じ結果を保証するものではありません。
