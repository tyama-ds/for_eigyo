ローカル LLM 社外秘 OK

社外秘文書の処理と、社外秘を含む回答に使います。社内サーバ・PC 上の LLM を指定してください。

クラウド LLM 公開文書のみ

公開文書の処理と、公開文書だけを根拠にする回答に使います。社外秘の本文は送られません。

データの取り扱い

社外秘文書の本文はどの設定でもクラウドへ送られません（プログラム側で強制）。 自動モードでは、社外秘資料を参照しない質問の文面はクラウドへ送られることがあります。

RAG の設定

グラフの作り方（文書ごとに「文書の情報」から別の方式でも作れます）

下のチェックは「自動」で使うかどうかです。「速さ優先」「選んで使う」は相談画面で選んだ方式を毎回使います。

DecisionRAG（arXiv:2610.35868）

判定 API の接続 — Decisions API（Jev / OpenAI / Azure OpenAI）

判定 API はテキストを生成せず、「この候補は質問に関連するか」を確率で答える判定専用のモデルです。 外部サービスのため公開文書の候補だけを判定させ、社外秘を含む段はローカル LLM で判定します （Azure OpenAI で「社外秘の候補も送ってよい」を ON にしたときを除く）。日本語の文書での精度は未確認です。

チャンクの文字数を変えたら「全文書を再処理」を実行してください。

音声入力（相談の文字起こし）

相談の 🎤 ボタンで、話した内容を質問欄に書き起こします。音声には質問の内容が入るため、 社内・ローカルの文字起こし（Whisper）を既定にし、クラウドへ送るのは下の許可を ON にしたときだけです。

Whisper 互換 API の接続（faster-whisper-server / whisper.cpp / LocalAI / Azure OpenAI 等）
