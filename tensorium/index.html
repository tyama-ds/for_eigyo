Augment · Knowledge Distillation

データ拡張 — LLM 知識蒸留で偏りを均衡化

目的変数が偏っている（少数クラスが極端に少ない）と、モデルは多数クラスばかり予測しがちです。教師 LLM に元データの傾向を学ばせて少数グループの合成データを生成し、教師 LLM の再ラベリングと学習済み生徒モデルの予測で検証したうえで学習データにのみ追加します（検証 / テストには混ぜません）。

⚗
