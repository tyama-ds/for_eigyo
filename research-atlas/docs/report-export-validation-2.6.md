# レポート出力 v2.6.0 の検証

2026-10-09、Windows / Python 3.11 以降のローカル環境で実施。

## 対象

全件レポート、重心・技術変化、年次、分野・隣接比較、有望領域、分析結果全体を共通のPDF / DOCX / XLSX / PPTXへ出力する。保存済みの本文・警告・対象範囲・集計・座標を使い、出力時にLLM生成や投影の再計算はしない。

生成途中の区分は状態を明記し、保存済みの本文を保持する。数値照合の警告も文書へ収録する。長い参照ID列は文書上で先頭12件と総数を示し、XLSX監査シートおよび既存CSV/JSONでは全情報を保持する。

## 自動検証

- Python全体: 1,628件成功、1件スキップ。新しい出力関連テスト66件を含む。
- JavaScript全体（`node --test tests/*.mjs`）: 262件成功。
- PDFの読み込み、日本語本文、DOCX/PPTX/XLSXの再読み込みと埋め込み画像を確認。
- 20,003件の合成レコードをXLSXへ出力し、全件の状態・抄録・抽出根拠を再読み込みで確認。約3.6MB、検証機で約27秒。
- Excelの長い文字列の分割・続き行、行数上限によるシート分割、数値/真偽値の型、数式に見える文字列のリテラル保存を検証。
- 図の所属する分析結果、PNG形式、枚数/サイズ/寸法上限、外部URLの拒否、二重出力抑止、候補選択範囲を検証。
- 全件レポートはSQLiteの同一読み取りスナップショットから本文・集計と論文記録を出力する。
- Windowsの時計分解能に依存した既存の処理時間テストを、抽出ダブルだけが進める時計に置き換えた。計測数の既存検証は維持。

## 画面と生成ファイル

合成869論文の保存済み分析を使用。全件の途中レポート（3件処理済み）と2023〜2024年の年次レポートを4形式ずつ作成。PDFは全件8ページ、年次26ページを画像化して確認した。表・注意事項・日本語本文と時層グラフの欠けや重なりは見られなかった。

ブラウザから時層展開図を追加して全件レポートのWordを実際にダウンロードし、標準図4枚と画面の時層図1枚の埋め込みを確認した。画面の年次推移図を選択して追加する操作と、PowerPointのダウンロードも確認した。

## 検証の限界

- Word / Excel / PowerPoint実アプリでの目視確認は未実施。OOXMLの内容と寸法、標準ライブラリでの再読み込みは検証済み。検証環境のOffice描画ランタイムはネイティブエラーで停止した。
- 図は静止画。回転操作や光る線のアニメーションは文書には入らない。
- 2万件の検証はファイル出力の検証であり、2万件を実LLMで解釈した試験ではない。
- 自動図の母集団と、画面から追加した図の表示範囲・投影・標本数はキャプションで区別する。表示点の平均を全コーパスの重心として扱わない。
