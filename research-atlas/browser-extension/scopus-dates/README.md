# Research Atlas — Scopus出版日補助拡張

Chrome / Edgeでログイン済みのScopus詳細画面から、Publication dateを取得します。Scopus APIキーは不要です。Research AtlasとはJSONファイルで受け渡します。

## 導入

1. Research Atlasの「出版日を補完」→「Scopusの画面から補完」から拡張のZIPを保存し、展開します。
2. Chromeは `chrome://extensions`、Edgeは `edge://extensions` を開き、「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、この `manifest.json` があるフォルダーを選びます。
4. 拡張のアイコンを押し、操作画面を開きます。同じブラウザーのプロファイルでScopusにログインしてください。

組織で拡張の導入が管理されている場合は、その導入手順に従ってください。別のブラウザーやプロファイルのログイン状態は引き継ぎません。

## 取得と取り込み

1. Research Atlasで対象データセットから取得リストJSONを保存します。初期値100件、1回の上限500件です。
2. 拡張の操作画面で取得リストを読み込み、「開始」で取得します。操作画面のタブを開いたままにします。文献は専用のScopusタブで順番に開きます。
3. 一時停止・画面を閉じる・ブラウザー終了後も完了した記録はブラウザー内に残ります。再開は操作画面から明示的に行います。ログイン要求や画面構造の変化で停止したら、専用タブの表示を確認してください。
4. 結果JSONを保存し、Research Atlasへ取り込みます。途中までの結果も取り込めます。
5. 元の日付と採用案を確認して「補完版データセット」を保存し、再分析します。

続きの取得リストは、結果を取り込んでから発行してください。成功した文献は除かれ、未取得分から継続します。失敗した文献の再試行は明示的に選びます。2万件を一度にタブ展開する機能ではありません。

## 抽出対象

- `dd[data-testid="document-info-publication-date"]` を優先します。
- 見つからない場合は、`Publication date` と表示された `dt` と、同じ行の `dd` を探します。
- CSSの自動生成クラス名には依存しません。必要な場合は `Show all information` の操作を試みます。
- URLの文献IDと画面の識別情報を確認し、別の文献・矛盾した日付・アクセス制限を成功扱いしません。
- 雑誌の巻号の年、著作権年、取得日から出版月日を推定しません。

## 保存と権限

拡張はScopusのページを開いてDOMにある日付を読みます。Cookie・パスワード・認証トークンは読み取りません。Research Atlasサーバーへの直接通信も行いません。ブラウザー内には取得リスト、完了した観測記録、進捗が残ります。結果JSONは文献ID・URL・日付の原文・取得方法・取得日時・状態を含みます。HTML全文や論文本文は含みません。

Scopus PreviewなどでPublication dateを閲覧できない場合は取得できません。ログイン画面やアクセス制限は回避しません。抽出処理は提供されたDOM構造と模擬画面で検証していますが、契約者向け実画面での大量取得は未検証です。初回は数件で表示内容と抽出結果を照合してください。
