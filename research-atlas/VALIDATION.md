# Research Atlas 配布版の動作確認

検証日: 2026-09-14

## 新規インストール

開発環境とは別のフォルダに公開対象のソースだけを配置し、新規の仮想環境へ `requirements.txt` を導入しました。Windows / Python 3.13 / Node.js 24.19.0で確認しています。開発環境の `.venv`、分析データ、APIキー、ブラウザ設定は複製していません。

- `pip check`: 依存関係の不整合なし。
- `python -m pytest tests -q`: **765 passed, 1 skipped**。追加パッケージが必要な実BERTopicテスト1件をスキップ。基本構成の分析・取込・API・保存・接続設定・引用照合・警告付き出力のテストを含みます。
- `node --test tests/*.mjs`: **79 passed**。接続設定のブラウザ保存、非同期処理、復元、ランドスケープ、評論と警告表示を含みます。
- `python -m unittest discover -s launcher -p "test*.py" -v`: **9 passed**。同時に追加されたPatent Atlasを含む既存アプリとの互換性、Windows/POSIXの仮想環境選択、未準備時の案内、直接起動を確認しました。リポジトリルートから実行します。
- PDFテストはCIと同じIPAexゴシックを指定して実行しました。フォント本体は配布ソースに含めません。

## App Portalの実起動

実際のアプリ専用仮想環境で、ポータルの起動処理から `run.py --no-browser --port 8778` を起動しました。

1. 起動前に8778番ポートが未使用であることを確認。
2. アプリのトップページがHTTP 200でResearch Atlasを返し、ポータルの状態が起動中に変化。
3. 停止操作後に8778番ポートが閉じ、管理プロセスとUvicornのプロセスが両方終了。

検証用保存先は一時フォルダに分離しました。既存の8000番アプリやユーザーの接続設定には変更を加えていません。

## 収録内容と確認範囲

公開対象はソース、合成テスト用fixture、導入手順、依存パッケージ定義です。`.env`、実際の論文データ、分析結果、生成PDF、ブラウザ設定、モデル重み、仮想環境、キャッシュは除外しています。主要APIキー・秘密鍵の形式を公開対象に検査し、該当なしでした。

数値照合が一致しないLLMの評論は、本文を保持して警告付きで保存・表示します。警告の再読込、PDF/CSVへの保持は自動テストに含まれます。根拠ID・原文・構造の不正や未完JSONの扱いは別です。詳細はREADMEを参照してください。

今回の配布確認では、実LLM・Scopus認証付きAPI・追加モデルのダウンロードを実行していません。LLMの文章の科学的妥当性や未来予測の精度を認定するテストではありません。

GitHub ActionsはWindowsとLinuxで基本構成のテストを実行します。各コミットの実行結果はリポジトリのActionsから確認してください。本番PC固有のネットワーク、LM Studio/Ollama、Scopus契約権限は導入先で確認が必要です。
