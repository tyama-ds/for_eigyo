接続・設定

01ローカルLLM

LM Studio、Ollama、vLLMなどのOpenAI互換APIに接続します。

通常は末尾に /v1 を含めます。LLMへの接続はプロキシを経由しません。

APIキーとプロキシのパスワードは、今回の起動中だけメモリーに保持します。アプリの再起動後は再入力してください。

一覧の取得時に、接続設定を保存します。

02Web・プロキシ

WebページはこのPCが取得します。Webアクセスをオンにした会話や、URLの添付に使われます。

認証ユーザー名がある場合は http://ユーザー名@ホスト:ポート の形式で入力します。

パスワードは今回の起動中だけ保持します。アプリの再起動後は再入力してください。

社内プロキシなどの証明書を信頼するための、PEMファイルのパス。
