# Mycel の使い方
このフォルダ（Vault）の中身はただの Markdown ファイルです。ほかのエディタで開いても構いません。

## Markdown の書き方
| 書きたいもの | 書き方 |
|---|---|
| 見出し | `# 大見出し` `## 中見出し` `### 小見出し`（`#` の数で階層） |
| 強調 | `**太字**` → **太字**、`*斜体*` → *斜体*、`~~取り消し~~` → ~~取り消し~~、`==蛍光==` → ==蛍光== |
| 箇条書き | 行頭に `- ` か `* `。字下げ（スペース 2 つ）で入れ子 |
| 番号つき | 行頭に `1. ` `2. ` |
| チェックボックス | `- [ ] やること` `- [x] 済み`（閲覧モードでクリックして切り替え） |
| 引用 | 行頭に `> ` |
| 区切り線 | `---` だけの行 |
| 表 | `\| 列1 \| 列2 \|` の行の次に `\|---\|---\|`（この表もそう書いています） |
| コード | 行内は `` `code` ``、複数行は ```` ``` ```` で囲む（``` ```python ``` のように言語名も可） |
| リンク | `[[ノート名]]`（下記）、外部は `[表示名](https://example.com)`。URL はそのまま書いてもリンクになります |
| 画像 | `![[添付/図.png]]`（`![[添付/図.png|400]]` で幅）または `![説明](添付/図.png)`。編集中に画像を貼り付け・ドロップすると自動で挿入されます |
| タグ | `#タグ名`（`#2026` のような数字だけは除く） |
| プロパティ | 先頭に `---` で囲んで `キー: 値`。`作成日: 2026-10-01` を書くと作成日として表示します |

## リンク
- `[[ノート名]]` で別のノートにつながります。まだ無いノート名を書いてクリックすると新しく作れます
- リンクを外すには、右の「リンク」タブ →「このノートからのリンク」の × を押します（本文の `[[ ]]` が文字に戻ります）
- `[[ノート名|表示名]]` で表示名を変えられます。`[[ノート名#見出し]]` で見出しへ
- `[[` と打つとノート名の候補が出ます
- 右の「リンク」タブに、このノートを参照しているノート（バックリンク）が出ます

## 整理
- `#タグ` を本文に書くと左の「タグ」から一覧できます
- 先頭に `---` で囲んだ `キー: 値` を書くとプロパティとして表示されます
- 左の📅でその日のデイリーノートを作ります。`テンプレート` フォルダのノートは新規作成時の雛形になります

## キーボード
- `Ctrl+K` ノートを開く / 新規作成（`Alt+N` で新しいノート）
- `Ctrl+Shift+F` 全文検索
- `Ctrl+E` 閲覧と編集の切り替え
- `Ctrl+S` 今すぐ保存（普段は自動保存）

## 資料と読み込み範囲
Word・Excel・PowerPoint・PDF・メール・テキスト・CSV・HTML・画像も「資料」として読み込み、検索・グラフ・AI の対象になります。
画像は開くとそのまま表示され、「AI で読む（VLM）」を押すと画像を読めるモデルが説明文を作り、その説明が検索・質問の根拠になります（設定の「LLM」で「画像を読むモデル」を登録。例: llava, qwen2.5vl, gemma3）。
左の ⛁ ボタン（またはステータスバーの件数）で **読み込み範囲** を開き、読み込むフォルダを選んだり、Vault の外のフォルダ（共有フォルダなど）を追加したりできます。

読み込みは初回だけ自動です。その後は、ステータスバーの **更新** を押したときだけ、変更されたファイルだけを読み込みます。
範囲ダイアログでフォルダを選んで「選択した範囲を更新」すると、その部分だけを読み込めます。

## 資料の整理とつながり
ファイル一覧の上で「資料」を選ぶと資料だけの階層表示になります。フォルダ名をクリックすると一覧が開き、ファイルをドロップして追加、まとめて移動・削除ができます。
資料には [[リンク]] を書けないので、資料を開いて右の「リンク」タブの「つながり」で他の資料・ノートとつなげます。「似ているものを探す（AI）」やフォルダの「つながりを提案」で候補も出せます。

## 文書・文献管理モード
左の本のアイコンで開きます。報告書・論文・調査資料を「文書」として登録すると、文書の本文だけを意味検索（RAG）したり、文書全体や **1 件だけ** を根拠に質問したりできます。
文書を開くと「AI の気づき」で、要点・関連する文書との共通点や相違点・残る疑問・次の一手を AI がまとめます。関連する文書は登録済みのものに加え、Vault 全体の未登録のノート・資料からも探します（その場で登録できます）。
グラフタブでは「タグ → 文書 → 章 → 段落」とクリックで分解でき、内容の近い章・段落は別の文書とも点線でつながります。

## Vault の切り替え
左の「ファイル」の横にあるフォルダのボタン（または設定の「切り替え…」）で、別の Vault（ノートを置くフォルダ）に移れます。最近使った Vault の一覧から戻ることも、新しい Vault（例: 文書管理専用）を作ることもできます。

## 作成日・更新日と版
ノートの題名の右に作成日と更新日が薄く出ます（マウスを乗せると時刻まで）。画面右下に Mycel の版（v0.6.0 など）が出ます。サーバの版と違うときは再起動の案内が出ます。

## 人物・組織
左の人のアイコンで、ノートや資料に出てくる人と会社の一覧が開きます。人をクリックすると、その人が「どの文書に・どんな立場で」出ているか、所属、一緒に出てくる人、関係がありそうな文書が見られます。「AI で人物像を推定」でまとめも作れます。間違っていたら × で外せます。

## AI 取り込み
長い文書（数百ページ）も既定では全文を読み、要点を節ごとにまとめてからノートにします。時間がかかるときは途中で止めても「続きから」再開できます。本文を入れる場合、6 万字を超える分は「本文 1..n」のノートに分かれます。
PDF や Word などの文書をアプリにドロップすると、ローカル LLM が読んで要約・要点・顧客名や人名のリンク・タグを付け、既存のノートとの関連も見つけた「つながったノート」の下書きを作ります。確認して保存してください。

## AI
右の「AI」タブで、Vault 全体に質問したり、ノートの要約・タグ提案・リンク候補を出したりできます。
LLM は左下の ⚙ 設定から登録します（OpenAI 互換 API / Azure OpenAI）。未設定でも関連ノートの検索は使えます。

質問の「方式」は既定の「標準（段落の検索）」のままで十分です。人や会社のつながりや全体の傾向を聞きたいときは
「GraphRAG」を選び、「GraphRAG の索引を作る」を押してから質問します（文書数に応じて時間がかかります。2 回目以降は変わった文書だけ）。
索引ができたら、グラフタブの「知識グラフ」をオンにすると実体と関係が文書のグラフに重なります。実体をクリックすると登場する文書が並び、
チェックして「チェックした文書をつなぐ」で文書同士を「つながり」として保存できます。
