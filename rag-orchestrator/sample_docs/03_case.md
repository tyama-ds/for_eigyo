# 導入事例集（抜粋）

## むつみ食品機械（食品機械メーカー）

充填ラインのポンプ 48 台に SkyEdge S-2 を導入。ベアリング摩耗による突発停止が年 11 回から
2 回に減り、ライン停止損失を年間約 3,800 万円削減した。導入の決め手は電池レスで防水区画にも
設置できる点だった。むつみ食品機械は効果を受けて、2024 年に全 3 工場への横展開を決定した。

## 東和精工（自動車部品）

プレス機 120 台の金型監視に SkyEdge S-1 と Gateway G-10 を採用。金型のクラックを早期に
検知し、不良流出をゼロ化した。東和精工は青嶺製作所のプレス加工部品事業の古くからの顧客でも
あり、自社工場での実績を踏まえて系列サプライヤー 8 社にも導入を推奨している。

## 北浜電機（制御盤・パートナー）

自社の制御盤製品に SkyEdge センサーを組み込んだ「スマート盤」を共同開発し、2023 年から
外販している。北浜電機経由の販売は SkyEdge 全体の約 35% を占め、資本業務提携の中核事業に
なっている。
