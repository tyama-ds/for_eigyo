# SkyEdge シリーズ 製品資料

SkyEdge は青嶺製作所の産業用ワイヤレスセンサーのブランドである。ラインアップは 3 機種。

- SkyEdge S-1: 振動・温度の複合センサー。工作機械の主軸監視向けのエントリーモデル。
- SkyEdge S-2: S-1 に電流計測を追加した上位機。モーターの劣化予兆検知に使われる。
- SkyEdge Gateway G-10: 最大 200 台のセンサーを束ねるゲートウェイ。エッジ側で異常度を
  スコア化してからクラウドへ送るため、通信量を約 9 割削減できる。

中核技術は 2 つある。ひとつは磁界共鳴方式の無線給電「AirFeed」で、センサー本体を完全
電池レスにできる。もうひとつは省電力無線プロトコル「LinkMist」で、2.4GHz 帯で 1000 台
規模の同時接続に耐える。どちらも CTO 柏木周平のチームが仙台開発センターで開発した。

異常検知アルゴリズムには自己教師あり学習を採用しており、正常データのみで学習できるのが
特徴である。このアルゴリズムは東北大学の田村研究室との共同研究の成果で、2023 年に
論文発表されている。

販売は直販に加えて、資本業務提携先である北浜電機の代理店網を通じて行う。
保守サービス「SkyEdge Care」は年額制で、センサーの校正と故障予兆レポートを含む。
